# RV University Department of Computer Applications

Responsive department website inspired by the provided RV University reference screenshots.

## Run locally

```bash
npm ci
npm run dev
```

Vite serves the site at `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The website uses React, Vite, Bootstrap styles, Lucide icons, Google Fonts, and Unsplash-hosted photography.
